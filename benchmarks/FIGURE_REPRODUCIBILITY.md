# Figure, Table, and Movie Reproducibility Map

This document maps every figure (`TOC`, `Figures 1–6`, `Supporting Figures S1–S14`), table (`Tables 1–2`, `Supporting Tables S1–S28`), and video (`Supporting Movies S1–S3`) in *Million-Atom Molecular Dynamics with Distillation and Foundation-Model Supervision* (X. Liu, Y. Wang, L. Shen) to the exact machine-readable data records in this dataset repository (`hf_release/data/`), the model checkpoints in the companion model repository (`hf_release/models/`), and the evaluation/driver scripts in `code_snapshot/mace-onegpu-jctc.tar.gz` (`code_release/mace-onegpu/`).
